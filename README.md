# Jashel's Portfolio

A personal portfolio website for Jashel Bert Ann P. Gupita, a 4th year student at Cebu Eastern College Incorporated. It introduces me, shows my skills, and presents my website projects. It works on phones and computers and is published with GitHub Pages.

**Live site:** https://gupitajbap.github.io/portfolio/

## About this project

I'm learning to build websites that are easy to read and work on any screen. This one-page site is made with HTML, CSS, and a little JavaScript. It includes:

- **Home:** my name, a short introduction, and my interests: front-end web development, UI design, and troubleshooting
- **About and skills:** my background, hobbies, and where I am today in HTML, CSS, JavaScript, Git and GitHub, and my capstone project
- **Projects:** my website projects with a screenshot, a short explanation, my contribution, and the tools I used
- **Contact:** my email, GitHub, and LinkedIn
- **Light and dark mode:** a moon/sun button in the menu switches the color theme

## Projects

### Maria's Tiny Prints Website
A printing services website for Maria's Tiny Prints, featuring a colorful homepage that showcases printing, photo printing, editing, laminating, and other services. This project helped me practice web development and website design.

- **My contribution:** I worked on the website layout, HTML structure, CSS styling, and page design. I also used XAMPP to run the project locally and test the website.
- **Tools:** HTML, CSS, JavaScript, XAMPP

### Alberto's Fresh Eggs Website
A business website for Alberto's Fresh Eggs that presents its egg products and provides customers with an easy way to inquire and place orders through Facebook Messenger. This project helped me learn how to create a business website and organize product information.

- **My contribution:** I worked on the website layout, designed the pages, displayed product information, and set up the local development environment using XAMPP.
- **Tools:** HTML, CSS, JavaScript, PHP, MySQL, XAMPP
